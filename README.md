# Портфолио — новая версия

Отдельный локальный черновик от 1 ноября 2026. Исходные `home-draft/` и `case-draft/` не изменены. Сайт не опубликован.

Страницы: [главная](index.html), [Открытие Брокер](otkritie.html), [Lightstream](lightstream.html).

Открой `index.html` в браузере. Сборка и установка зависимостей не нужны. Для локального HTTP-предпросмотра из папки проекта:

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory site-v2
```

Затем открой <http://127.0.0.1:8767/>. Остановка — Ctrl+C.

## Основа

Вёрстка опирается на последние согласованные макеты [главной](https://www.figma.com/design/JlAXgOND69cIqCTDr8JZfe/?node-id=2296-41910) и [кейса](https://www.figma.com/design/JlAXgOND69cIqCTDr8JZfe/?node-id=2293-29267): повторяемая сетка, Inter Black для H1, Inter Regular/Medium для рассказа и заголовков, IBM Plex Mono Medium для меток. Палитра: белый, #D9D9D9, #1B1B1B, #EE3F24, #182584. Есть адаптивная вёрстка, переходы между страницами и увеличение изображений по нажатию. Шрифты хранятся локально вместе с лицензиями OFL.

Тексты взяты из прежних HTML. Сохранены регалии, показатели и содержательные оговорки. Lightstream оформлен в общей системе. Фоны футеров собраны CSS-градиентами, зерно — SVG-фильтром.

## Проверка

Проверены локальные пути, якоря, синтаксис JavaScript и сохранность прежних черновиков. В браузере проверены загрузка главной с портретом и переход к кейсу. Полная визуальная проверка страниц и мобильного режима осталась незавершённой из-за сбоя управления браузером. Публикация, отправка контактов и сторонние аналитические скрипты отсутствуют.
